# AIActRAG

A fully local **Retrieval-Augmented Generation (RAG) chatbot** based on the European Union AI Act.

This project explores how RAG works, from document processing and embeddings to retrieval and answer generation, using free and open-source tools.

### Progress
- Extracted and cleaned the AI Act from EUR-Lex.
- Structured 119 articles with metadata.
- Implemented an initial chunking strategy (one chunk per article).
- Analyzed chunk lengths to prepare for embedding and retrieval.

### Next
Implement embeddings, semantic retrieval, and local answer generation, then experiment with different chunking strategies to evaluate retrieval quality.

**Status:** In development
